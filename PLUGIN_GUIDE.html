Tuya Fan

Local LAN control of compatible Tuya ceiling fan controllers from Universal Devices eisy / PG3x.
Local Tuya ControlTinyTuyaIoX / eisyPG3x

Overview

Tuya Fan presents compatible Tuya ceiling fan controllers as native IoX nodes. Normal operation is performed directly over the local LAN using TinyTuya; Tuya cloud access is not required after the Device ID and Local Key have been obtained.

Fan ControlFan On/Off and six fan speeds.
Operating ModesNormal, Sleep, and Natural modes.
DirectionForward and Reverse fan direction.
Light ControlLight On/Off and brightness from 0–100%.
Stop TimerOff, 1 Hour, 2 Hours, 4 Hours, or 8 Hours.
Multiple FansConfigure up to 16 independent fan controllers.

Configuration

Each fan is configured using PG3x Custom Parameters. The parameter number corresponds to the fan number.

ParameterPurpose
fan1_nameDisplay name shown in IoX.
fan1_idTuya Device ID.
fan1_ipLocal IP address of the fan controller.
fan1_keyTuya Local Key.
fan1_versionTuya protocol version. Tested controllers use 3.4.

For additional fans use fan2_*, fan3_*, and so on through fan16_*.

Recommended: assign each fan a DHCP reservation so its local IP address does not change.

After changing Custom Parameters, save the changes and restart the plugin.

Fan Speed behavior: setting a fan speed automatically turns the fan on before applying the requested speed. This allows an IoX scene to turn on a fan and select its speed using a single responder command.

Using IoX Scenes

IoX scenes can use the fan node as a responder. Because a responder normally selects one command for the node, the Fan Speed command automatically includes Fan On behavior.

For example, four keypad buttons can provide simple preset control:

SceneFan Responder Command
HighFan Speed 6
MediumFan Speed 4
LowFan Speed 2
OffFan Off

A speed command therefore works whether the fan is already running or currently off.

Smart Life / Tuya Setup

Before the plugin can control a fan locally, you must obtain several pieces of information about the Tuya device: its Device ID, Local Key, local IP address, and Tuya protocol version. The easiest method is to first add the fan to Smart Life or Tuya Smart, create a Tuya developer project, and then run the TinyTuya setup wizard on the eisy.

1. Add the Fan to Smart Life or Tuya Smart

  1. Install Smart Life or Tuya Smart on your phone.
  2. Pair the fan/controller with the app in the normal manner.
  3. Verify that the fan can be controlled successfully from the app before continuing.
The Smart Life and Tuya Smart apps use the Tuya platform. The plugin does not control the fan through the mobile app; the app is used during initial setup so the device can be associated with your Tuya account.

2. Create a Tuya IoT Developer Project

Using a web browser, go to Tuya IoT Platform and create or sign into a Tuya IoT developer account.

  1. Create a new Cloud project for Smart Home devices.
  2. Select the data center/region corresponding to the Smart Life or Tuya Smart account used to pair the fan.
  3. Open the project Overview page.
  4. Locate the project's Access ID / Client ID and Access Secret / Client Secret. These will be used by the TinyTuya wizard.

3. Link Your Smart Life / Tuya Smart Account

  1. In the Tuya IoT project, open the Devices section.
  2. Select Link Tuya App Account.
  3. Select Add App Account.
  4. A QR code will be displayed.
  5. Open Smart Life or Tuya Smart on your phone and use its QR-code scanner to scan the code.
  6. Confirm the account link.
  7. Verify that the fan appears in the Tuya IoT project device list.

4. Connect to the eisy Using SSH

SSH provides a command-line connection to the eisy. No additional SSH software is normally required on current versions of Windows.

Find the eisy IP Address

Find the eisy in your router's client/device list and note its local IP address. An address will typically look something like:

192.168.1.50

Your address will probably be different. Use the actual IP address assigned to your eisy.

Open a Terminal in Windows

  1. Right-click the Windows Start button.
  2. Select Terminal. Windows PowerShell or Command Prompt may also be used.
  3. At the prompt, enter ssh admin@ followed by the eisy IP address.

For example:

ssh admin@192.168.1.50

First SSH Connection

The first time you connect to an eisy, SSH may display a message similar to:

The authenticity of host '192.168.1.50' can't be established.
Are you sure you want to continue connecting (yes/no/[fingerprint])?

Type:

yes

Log In

The default eisy SSH login is:

Usernameadmin
Passwordadmin

If the password has previously been changed, use the current password instead.

Important: when typing an SSH password, nothing appears on the screen—not even dots or asterisks. Type the password normally and press Enter.

After a successful login, you should see a command prompt similar to:

[admin@eisy ~]$

You are now operating at the eisy command line.

5. Install TinyTuya and Run the Wizard

At the eisy SSH prompt, first make sure TinyTuya is installed:

python3 -m pip install --user --upgrade tinytuya

After the installation completes, run the TinyTuya setup wizard:

cd /home/admin
python3 -m tinytuya wizard

The TinyTuya wizard will ask for information from the Tuya IoT project, including the API/Access ID, API/Access Secret, Device ID, and region. If TinyTuya has been configured previously, it may display the saved settings and ask:

Use existing credentials (Y/n):

Press Enter to accept the existing credentials, or answer n if new Tuya project credentials need to be entered.

The wizard will then ask whether to download DP name mappings. Answer y. DP (Data Point) mappings provide descriptive information about the functions exposed by Tuya devices.

Download DP name mappings? (Y/n): y

When asked whether to poll local devices, answer y:

Poll local devices? (Y/n): y

TinyTuya will scan the local network for Tuya devices and attempt to communicate with them directly. A successful scan will look similar to:

Scanning local network for Tuya devices...
    2 local devices discovered

Polling local devices...
    [Patio Fan East] 192.168.1.50 - [On] - DPS: {...}
    [Patio Fan West] 192.168.1.51 - [On] - DPS: {...}

>> Saving device snapshot data to snapshot.json
>> Saving IP addresses to devices.json

Done.

The names and IP addresses shown above are only examples. Your devices and addresses will be different.

When successful, TinyTuya creates or updates:

/home/admin/devices.json

The devices.json file contains the Tuya device information needed to configure the plugin, including Device IDs, Local Keys, and discovered local IP addresses.

6. Identify the Fan Information

For each fan you intend to configure, identify:

ValueDescription
Device IDThe unique Tuya identifier for the fan/controller.
Local KeyThe key used to authenticate local LAN communication.
IP AddressThe fan controller's current LAN address.
Protocol VersionThe Tuya local protocol version. The FC86B5-5D controllers tested with this plugin use 3.4. Other controllers may use a different version.

7. Enter the Information in PG3x

Open the Tuya Fan plugin in PG3x and enter the information under Custom Configuration Parameters.

For the first fan:

ParameterValue
fan1_nameA friendly name, such as Patio Fan East
fan1_idTuya Device ID
fan1_ipLocal IP address
fan1_keyTuya Local Key
fan1_versionProtocol version, typically 3.4 for tested hardware

Additional fans use fan2_*, fan3_*, and so forth.

8. Save and Restart the Plugin

  1. Save the Custom Configuration Parameters.
  2. Restart the Tuya Fan plugin.
  3. Open IoX and verify that the fan node appears.
  4. Test Fan On, Fan Off, and Fan Speed.
Normal operation is local: once setup is complete, the plugin communicates directly from the eisy to the fan over your LAN. The Tuya cloud and Smart Life/Tuya Smart app are not in the normal control path.

Local Operation

IoX Command→Tuya Fan Plugin→TinyTuya→Local Fan Controller

Once configured, normal fan control and status polling occur directly between eisy and the Tuya device over the LAN.

Internet or Tuya cloud availability is therefore not required for routine fan operation.

Troubleshooting

  • If a fan's IP address changes, update the corresponding fan*_ip parameter or use a DHCP reservation.
  • If a device is reset, removed, or re-paired, its Local Key may change. Run the TinyTuya wizard again to obtain the current key.
  • Local communication failure: if the fan continues to work through the Smart Life/Tuya app but stops responding to the plugin, completely power-cycle the fan/controller by removing AC power and restoring it. Testing has shown that a controller can remain online and accessible through the Tuya cloud while its local Tuya protocol stops responding. A full power cycle can restore local LAN communication.
  • After changing Custom Parameters, restart the plugin.

Security Notes

  • The Tuya Local Key is a credential. Do not publish it or commit it to Git.
  • Do not include Local Keys, Tuya API secrets, or other credentials in screenshots, logs, or public support requests.
  • Configuration credentials are stored in PG3x Custom Parameters rather than in this repository.
